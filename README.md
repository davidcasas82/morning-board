# morning-board

Kids morning leave-by countdown for an old Surface Pro kiosk.

**v1 is one shared clock** — the household time left before everyone leaves. Not a clock per kid. A dashboard can come later.

This pass is planning only. See [PLAN.md](PLAN.md). Weekday times live in [schedule.json](schedule.json). Friday 6:35 → 7:45 is confirmed; Mon–Thu are placeholders for David to correct.

To feel the idea on the tablet, open [kiosk.html](kiosk.html) in Edge or Chrome and tap for fullscreen. It is a static mock, not the full app.
